# 素材版权与使用范围

本目录下的素材由「原图 + 成品 PPTX + 成品预览」三部分组成：

- **原图.jpg**：来自 EdrawMax 公开模板库及网络公开设计稿，版权归原作者 / 原平台所有。
- **成品.pptx**：由 [image2ppt.asia](https://image2ppt.asia) 从原图自动重建，
  文字为原生文本框，色块、箭头、图标为原生形状。
- **成品预览.jpg**：成品的渲染图，仅用于预览。

## 你可以

- 自由修改成品 PPTX 的文字、配色、图形和版式，用于个人学习、教学、内部汇报。
- 在非商业场合引用、展示或改编成品。

## 你不可以

- 将原图或成品原样转售、打包售卖，或二次分发到付费素材站。
- 声称原设计稿为你本人原创。
- 将素材用于需要明确商业授权的场景（商用前请自行确认原设计稿的授权）。

## 免责声明

本仓库仅用于学习、研究与展示「图片 → 可编辑 PPT」的转换效果。
如原作者认为某页素材不宜公开，请提 Issue，我们会尽快移除。

## 怎么用

1. 在下面的分类表里点 **PPTX** 下载（标 ★ 的在仓库内，其余跳到站点单页下载，免登录）。
2. 用 PowerPoint / WPS / Keynote 打开，双击任意文字即可修改。
3. 想确认「真可编辑」，做三个动作：
   - 双击标题，出现**文字光标**（不是弹出一张图片）；
   - 点击色块或箭头，出现**形状控制点**；
   - 打开「开始 → 选择窗格」，看到一长串**独立对象**。

> 标 ★ 的素材在 `materials/<分类>/<素材名>/` 下，含 `原图.jpg`、`成品.pptx`、`成品预览.jpg`，可以直接对照原图看哪些内容被重建成原生对象。
